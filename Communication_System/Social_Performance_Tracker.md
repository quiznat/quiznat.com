# Social Performance Tracker

Track, analyze, iterate. This is a living document.

---

## Metrics That Matter

**Primary (algorithm signals):**
- Shares (especially private/DM shares)
- Comments (meaningful > emoji reactions)
- Saves

**Secondary:**
- Reach (organic only)
- Reactions
- Link clicks

**Ignore:**
- Follower count (vanity metric)
- Impressions without engagement

---

## Weekly Review Process

After each week:

1. **Log metrics** for each post (template below)
2. **Identify winner** - highest shares + comments
3. **Identify loser** - lowest engagement
4. **Analyze why** - hook type, emotion, length, timing
5. **Update learnings** - add to What Works / What Doesn't
6. **Adjust next week** - double down on winners, cut losers

## Experiments Queue

Ideas to test in future weeks:

1. **Shorter posts** - Try sub-50 character posts
2. **Question hooks** - Open with question, no answer
3. **Controversial/contrarian** - "Unpopular opinion:" format
4. **User stories** - Feature player experiences (if any)
5. **Behind-the-scenes process** - How cards are made
6. **Seasonal tie-ins** - Holidays, back-to-school, etc.
7. **Meme formats** - Adapt trending templates
8. **Color background posts** - Facebook native format

---

## Iteration Rules

1. **Winner pattern** → Use 2x next week
2. **Loser pattern** → Cut or radically change
3. **Flat performance** → Test one variable change
4. **Breakout post** → Analyze deeply, document in Hook_Library.md
5. **All posts flat** → Research new approaches, update playbook
