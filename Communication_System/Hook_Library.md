# Hook Library

Proven opening hooks organized by type. Use these as templates, not copy-paste.

---

## Pattern Interrupts

Break expectations to capture attention.

```
This may be controversial but...
Everything you knew about ___ is 100% WRONG
I'm going to say something unpopular.
Stop doing ___.
```

---

## Curiosity Gaps

Create tension that must be resolved.

```
I couldn't believe (person)'s reaction to __
This is why your ___ isn't working...
There's something nobody tells you about ___
I didn't expect this to happen.
```

---

## Transformation Stories

Promise change or results.

```
From $0 to $10k in 30 days
I kept getting [pain point], so I tried this instead
Before/After: ___
This changed everything.
```

---

## Numbered Lists

Specific, scannable value.

```
4 things you're NOT doing to improve __
Here are 2 signs that you should stop doing XX
3 reasons ___ doesn't work
One thing.
```

---

## Contrarian Statements

Challenge popular beliefs.

```
Vulnerability is Power
Instead of buying this (popular product), I have another recommendation...
___ isn't the problem. ___ is.
Everyone's wrong about ___.
```

---

## Social Proof

Leverage popularity.

```
200+ people asked me about...
This [product type] has over 5,000 reviews...
I've seen this mistake 100 times.
```

---

## FOMO/Urgency

Time-sensitive pressure.

```
This video is only for X people, so keep scrolling if that's not you.
Before this disappears...
You're running out of time to ___
```

---

## Relatable Targeting

Make audience feel seen.

```
If you're like me and do X, then this one is for you.
___ type of people... stop scrolling!
Parents, this one's for you.
If you've ever ___, you know.
```

---

## Universal Moments

Tap shared experiences.

```
There's this moment when...
You know that feeling when...
We've all been there.
Nobody talks about this part.
```

---

## Confession Format

Vulnerability creates connection.

```
I have to admit something.
Here's what I got wrong.
I used to think ___. I was wrong.
Confession:
```

---

## Question Hooks

Trigger internal response.

```
Why does ___ feel so hard?
What if ___ wasn't the problem?
Have you ever noticed...?
When was the last time you ___?
```

---

## Story Starters

Promise narrative payoff.

```
It started with...
I never expected to...
Three years ago...
The moment I knew:
```

---

## Emotional Anchors

Lead with feeling.

```
This broke me.
I wasn't ready for this.
Pure joy.
This is why I do this.
```

---

## Parent-Specific Hooks

For family/parenting content.

```
"Can I have more screen time?"
There's this moment when a kid figures something out.
Nobody warns you about this part of parenting.
You see it before they say anything.
My kid taught me something today.
If you've ever lost to a 5-year-old...
```

---

## Anti-Hooks (Avoid These)

These kill engagement:

```
Quick tip: [anything]
Did you know that...
We're excited to announce...
Check out our new...
Here at [brand], we...
[Any corporate opener]
```

---

## Hook Testing Checklist

Before posting, ask:

1. Would I stop scrolling for this?
2. Does the first line create curiosity?
3. Is there an actor (someone doing something)?
4. Is there emotion in the first 10 words?
5. Would someone DM this to a specific friend?
